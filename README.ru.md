## Зачем Centrio?

У тебя открыт Telegram в одном окне, WhatsApp в другом, Discord в третьем. Gmail во вкладке браузера. Notion где-то ещё. Slack пингует в фоне.

**Centrio собирает всё это в одном месте** — единое десктопное приложение, где каждый сервис живёт в своей вкладке, уведомления объединены, а 14 вкладок браузера наконец можно закрыть.

## Возможности

### 🗂️ 100+ сервисов в одном сайдбаре

Telegram · WhatsApp · Discord · VK · Slack · Notion · Gmail · Signal · Zoom · WeChat · LINE · Figma · Jira · MAX · и любой URL, который добавишь вручную.

### 🤖 ИИ-ассистент *(Pro/Team)*

Спроси обычным текстом — и он сам всё сделает: переключит вкладку, посчитает непрочитанные, прочитает уведомления из колокольчика, включит/выключит VPN, поставит на паузу мини-плеер, создаст или закрепит заметку.

### 📝 Заметки *(Pro/Team)*

Полноценный плагин заметок, а не довесок: обычные заметки и списки покупок с синхронизацией между всеми устройствами.

- 🔍 Полнотекстовый поиск по заметкам и пунктам списков
- 🎨 Шесть цветных меток для быстрой визуальной сортировки
- 🗄️ Архив — убрать заметку с глаз долой, не удаляя
- ↕️ Сортировка перетаскиванием
- 📌 Закрепление, 📋 дублирование и дата последнего изменения на каждой карточке

### 🛡️ Встроенный VPN

Без сторонних приложений. Импортируй ссылку с конфигом и подключись в один клик.

| Протокол | Формат ссылки |
|----------|--------------|
| VLESS | `vless://...` |
| VMess | `vmess://...` |
| Trojan | `trojan://...` |
| Shadowsocks | `ss://...` |
| Hysteria2 | `hy2://...` |
| Подписка | URL со списком конфигов |

Индикатор пинга (зелёный / жёлтый / красный), флаг страны, таймер соединения, автопереключение на резервный сервер, маршрутизация трафика для всех сессий.

### 🎵 Мини-плеер

Иконка в сайдбаре появляется сама, как только в любой открытой вкладке начинает играть аудио или видео — пауза, следующий и предыдущий трек без переключения на эту вкладку.

### 🧩 Расширения Chrome *(Pro/Team)*

Установи AdBlock, Grammarly, переводчик и другие расширения прямо внутри Centrio — отдельный браузер не нужен.

### ✅ Задачи

Лёгкий планировщик задач со своими категориями (списками) — добавляй, отмечай важное звёздочкой, выполняй, удаляй как отдельные задачи, так и целые списки.

## Сборка из исходников

```bash
git clone https://github.com/Centrio-me/centrio-app.git
cd centrio-app
npm install
cp .env.example .env   # заполни OAuth-креды
```

```bash
npm start              # разработка
npm run build:win      # → dist/Centrio Setup x.x.x.exe
npm run build:mac      # → dist/Centrio-x.x.x.dmg
npm run build:linux    # → dist/Centrio-x.x.x.AppImage + .deb
```

**Требования:** Node.js 22+, npm 10+

## CI/CD

Каждый тег `v*` запускает мультиплатформенную сборку через GitHub Actions:

```
git tag v2.x.x && git push origin v2.x.x
        │
        ├─ build-win   (windows-latest)  →  .exe
        ├─ build-mac   (macos-latest)    →  .dmg
        └─ build-linux (ubuntu-latest)   →  .AppImage + .deb
                │
                └─ deploy  →  загрузка на download.centrio.me
```

Нужные секреты: `SSH_HOST`, `SSH_USER`, `SSH_PASSWORD`, `GOOGLE_DESKTOP_CLIENT_ID`, `GOOGLE_DESKTOP_CLIENT_SECRET`, `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `TELEGRAM_BOT_ID`

## Архитектура

```
centrio-app/
├── main.js                  # точка входа главного процесса Electron
├── preload.js                # contextBridge preload (главное окно)
├── webview-preload.js        # preload, инжектится в каждый <webview> мессенджера
├── vpn-manager.js             # менеджер процесса sing-box
├── main/
│   ├── bootstrap/            # инициализация приложения, создание окна, регистрация IPC
│   ├── factory/               # фабрики BrowserWindow / модальных окон
│   ├── ipc/                   # VPN, прокси, OAuth, ассистент, заметки, апдейтер...
│   └── services/              # store, secure storage, entitlement, aiProviders...
├── renderer.js                # точка входа рендерера — подключает все renderer/*.js
├── renderer/                  # чистый JS + esbuild, отдельный модуль на фичу
│   ├── assistant-bind.js      # UI чата ИИ-ассистента
│   ├── notes-bind.js          # плагин Заметки
│   ├── media-player-ui.js     # мини-плеер
│   ├── vpn-bind.js            # панель VPN
│   └── settings-bind.js       # панель настроек
├── landing/                   # исходники сайта (Next.js, деплоится отдельно)
└── .github/workflows/
    └── build.yml               # мультиплатформенный CI/CD
```
