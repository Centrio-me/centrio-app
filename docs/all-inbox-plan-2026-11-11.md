# «Все мессенджеры» — ночной план (2026-11-11)

Цель владельца: собственный обработчик сообщений со всех мессенджеров — красиво, современно, «пока не вылижем всё возможное».
Сейчас: список чатов Telegram + MAX, своё окно переписки как в Telegram (альбомы, ответы, файлы, эмодзи, фоны, черновики, «печатает»).

Правила проверки: тестовая копия сессии владельца `C:/tmp/ap`; писать только в MAX «Андрей Горячев» и Telegram «Избранное»;
чаты с непрочитанными не открывать; скриншоты с чужой перепиской никуда наружу.

## 1. Список чатов — как в Telegram, но для всех сразу
- [ ] Строка в две линии вместо трёх: имя · время / превью · счётчик. Значок мессенджера на аватарке; имя аккаунта
      (Рабочий, Telegram, MAX) — маленькой меткой у имени и только когда аккаунтов одного мессенджера больше одного.
- [ ] Статус своего последнего сообщения в списке (✓ / ✓✓) и «Вы:» как в Telegram.
- [ ] Вид чата: личный / группа / канал → фильтры «Все · Непрочитанные · Личные · Группы · Каналы».
- [ ] Закреплённые чаты сверху (как в мессенджере), значок булавки; без звука — серый счётчик и перечёркнутый динамик.
- [ ] Онлайн-точка на аватарке у личных чатов (Telegram знает статус).
- [ ] Поиск: значок, крестик очистки, Ctrl+F / «/» ставит курсор, совпадение подсвечено в имени.
- [ ] Ряд мессенджеров: прокрутка колёсиком, мягкое затухание по краям.
- [ ] Клавиатура: ↑/↓ по списку, Enter открывает, Esc закрывает окно переписки.
- [ ] Скелетон при первой загрузке вместо пустоты; понятные пустые состояния.

## 2. Окно переписки
- [ ] Шапка: «в сети» / «был(а) …» / «N участников» / «печатает…» вместо «6 сообщений · Рабочий».
- [ ] Плавающая дата при прокрутке (как в Telegram), разделитель «Непрочитанные сообщения».
- [ ] Просмотр фото: на весь экран, листание стрелками по всем фото чата, масштаб колёсиком, Esc.
- [ ] Отправка без ожидания: сообщение сразу в ленте с часиками, потом заменяется настоящим.
- [ ] Поиск по переписке (Ctrl+F в открытом чате) с подсветкой и переходом ↑/↓.
- [ ] Анимация открытия, скелетон пока чат грузится.

## 3. Больше мессенджеров
