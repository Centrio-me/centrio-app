# «Все мессенджеры» — ночной план (2026-11-11)

Цель владельца: собственный обработчик сообщений со всех мессенджеров — красиво, современно, «пока не вылижем всё возможное».
Было: список чатов Telegram + MAX, своё окно переписки как в Telegram (альбомы, ответы, файлы, эмодзи, фоны, черновики, «печатает»).

Правила проверки: тестовая копия сессии владельца `C:/tmp/ap`; писать только в MAX «Андрей Горячев» и Telegram «Избранное»;
чаты с непрочитанными не открывать; скриншоты с чужой перепиской никуда наружу.

## 1. Список чатов — как в Telegram, но для всех сразу
- [x] Две строки вместо трёх: имя · время / превью · счётчик. Аккаунты одного мессенджера — цветное кольцо на значке
      (тот же цвет у кнопки аккаунта сверху), имя аккаунта — во всплывающей подсказке.
- [x] ✓ / ✓✓ своего последнего сообщения.
- [x] Вид чата → фильтры «Все · Непрочитанные · Личные · Группы · Каналы» (MAX: группа = превью «Автор: текст»).
- [x] Закреплённые сверху с булавкой; без звука — перечёркнутый динамик и серый счётчик.
- [x] Точка «в сети» у людей (Telegram, статус переспрашивается при каждом чтении).
- [x] Поиск: значок, крестик, Ctrl+F и «/», совпадение подсвечено.
- [x] Ряды фильтров и мессенджеров листаются колёсиком, края затухают.
- [x] ↑/↓/Enter по списку, Esc очищает поиск.
- [x] Серые строки при первой загрузке; цветные аватарки с инициалами.
- [x] «Черновик:» красным (свой несохранённый текст или черновик Telegram), «@» для упоминаний.
- [x] «печатает…», «записывает голосовое»… в списке акцентным цветом.
- [x] Чат, поднятый новым сообщением, плавно едет на место; неизменившиеся строки не пересобираются.

## 2. Окно переписки
- [x] Шапка: статус из самого мессенджера (Telegram и теперь MAX: «Был(-а) вчера в 21:12»), «в сети» акцентом.
- [x] Плавающая дата при прокрутке (только при прокрутке человеком).
- [ ] Разделитель «Непрочитанные сообщения» — не проверить без открытия чатов с непрочитанными (запрещено на живом аккаунте).
- [x] Просмотр фото на всё окно: листание по всем фото чата, «3 из 17», масштаб колёсиком, перетаскивание, Esc.
- [x] Отправка без ожидания: сообщение сразу в ленте с часиками, потом заменяется настоящим; при ошибке всё возвращается в поле.
- [x] Поиск по переписке (Ctrl+F / лупа) с подсветкой и переходом ↑/↓.
- [x] Серые пузыри при загрузке, мягкое появление; Esc закрывает чат.
- [x] Пузырь с фото/альбомом шириной ровно с фото (посты каналов больше не растягиваются).
- [x] Альбом из MAX (фото с разницей в пару минут).
