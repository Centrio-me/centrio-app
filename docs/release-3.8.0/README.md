**Centrio 3.8 — все мессенджеры в одном окне** ✨

Самое большое обновление за всё время. Теперь не нужно прыгать по вкладкам, чтобы ответить всем.

💬 **Все мессенджеры** (ПРО, альфа-версия)
Чаты Telegram, WhatsApp, MAX, ВКонтакте и Instagram — в одном списке, свежие сверху. Открываете чат — переписка тут же, в окне Centrio: отвечайте, отправляйте файлы и эмодзи, слушайте голосовые, листайте фото.
• Фильтры: непрочитанные, личные, группы, каналы
• Поиск по чатам и Ctrl+F по переписке
• Прочитали в Centrio — прочитано и в мессенджере
• Черновики помнятся у каждого чата
• Опросы Telegram и ВК — голосуйте прямо здесь

Режим в альфа-тестировании: наведите на значок «α» и нажмите «Оставить отзыв». Каждое сообщение читаем сами.

🌙 **Тихие часы для личного**
Просили — сделали. В «Моём графике» у каждого сервиса: «Всегда», «Рабочий» или «Личный». Рабочие молчат вечером и в выходные, личные не отвлекают днём. Сообщения не теряются — ждут в центре уведомлений.
