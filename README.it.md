## Perché Centrio?

Hai Telegram aperto in una finestra, WhatsApp in un'altra, Discord in una terza. Gmail in una scheda del browser. Notion da qualche parte. Slack che continua a suonare in background.

**Centrio riunisce tutto in un unico posto** — un'unica app desktop dove ogni servizio vive nella sua scheda, le notifiche sono unificate, e finalmente puoi chiudere 14 schede del browser.

---

## Funzionalità

### 🗂️ Oltre 100 servizi, un'unica barra laterale

Telegram · WhatsApp · Discord · VK · Slack · Notion · Gmail · Signal · Zoom · WeChat · LINE · Figma · Jira · MAX · e qualsiasi URL aggiunto manualmente.

### 🤖 Assistente IA *(Pro/Team)*

Chiediglielo in linguaggio naturale e se ne occupa lui: cambia scheda, controlla i messaggi non letti, legge la campanella delle notifiche, controlla la VPN integrata, gestisce il mini player e le tue Note — creando, bloccando in alto ed eliminando voci su richiesta.

### 📝 Note *(Pro/Team)*

Un vero plugin per le note, non un ripiego: note semplici e liste della spesa, sincronizzate su tutti i dispositivi.

- 🔍 Ricerca full-text tra note e voci delle liste
- 🎨 Sei etichette colorate per un ordinamento visivo rapido
- 🗄️ Archivio — metti da parte una nota senza eliminarla
- ↕️ Riordino con trascinamento
- 📌 Blocco in alto, 📋 duplicazione e data dell'ultima modifica su ogni scheda

### 🛡️ VPN integrata

Nessuna app di terze parti necessaria. Importa un link di configurazione e connettiti con un clic.

| Protocollo | Formato di importazione |
|------------|--------------------------|
| VLESS | `vless://...` |
| VMess | `vmess://...` |
| Trojan | `trojan://...` |
| Shadowsocks | `ss://...` |
| Hysteria2 | `hy2://...` |
| Abbonamento | URL con elenco di configurazioni |

Indicatore di ping (verde / giallo / rosso), bandiera del paese, timer di connessione, passaggio automatico a un server di riserva, instradamento del traffico per tutte le sessioni.

### 🎵 Mini player multimediale

Un'icona appare nella barra laterale non appena inizia la riproduzione di audio o video in una scheda aperta — pausa, traccia successiva e precedente senza passare a quella scheda.

### 🧩 Estensioni Chrome *(Pro/Team)*

Installa AdBlock, Grammarly, un traduttore e altre estensioni direttamente in Centrio — non serve un browser separato.

### ✅ Attività

Un pianificatore di attività leggero con categorie (liste) proprie — aggiungi, contrassegna con una stella, completa ed elimina sia singole attività che intere liste.

## Compilare dai sorgenti

```bash
git clone https://github.com/Centrio-me/centrio-app.git
cd centrio-app
npm install
cp .env.example .env   # inserisci le credenziali OAuth
```

```bash
npm start              # sviluppo
npm run build:win      # → dist/Centrio Setup x.x.x.exe
npm run build:mac      # → dist/Centrio-x.x.x.dmg
npm run build:linux    # → dist/Centrio-x.x.x.AppImage + .deb
```

**Requisiti:** Node.js 22+, npm 10+

## CI/CD

Ogni tag `v*` avvia una build multipiattaforma tramite GitHub Actions:

```
git tag v2.x.x && git push origin v2.x.x
        │
        ├─ build-win   (windows-latest)  →  .exe
        ├─ build-mac   (macos-latest)    →  .dmg
        └─ build-linux (ubuntu-latest)   →  .AppImage + .deb
                │
                └─ deploy  →  upload su download.centrio.me
```

Secret richiesti: `SSH_HOST`, `SSH_USER`, `SSH_PASSWORD`, `GOOGLE_DESKTOP_CLIENT_ID`, `GOOGLE_DESKTOP_CLIENT_SECRET`, `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `TELEGRAM_BOT_ID`

## Architettura

```
centrio-app/
├── main.js                  # punto d'ingresso del processo principale Electron
├── preload.js                # contextBridge preload (finestra principale)
├── webview-preload.js        # preload iniettato in ogni <webview> del messenger
├── vpn-manager.js             # gestore del processo sing-box
├── main/
│   ├── bootstrap/            # inizializzazione app, creazione finestra, IPC
│   ├── factory/               # factory di BrowserWindow / finestre modali
│   ├── ipc/                   # VPN, proxy, OAuth, assistente, note, updater...
│   └── services/              # store, storage sicuro, entitlement, aiProviders...
├── renderer.js                # punto d'ingresso del renderer — collega tutti i renderer/*.js
├── renderer/                  # JS puro + esbuild, un modulo per funzionalità
│   ├── assistant-bind.js      # UI della chat dell'assistente IA
│   ├── notes-bind.js          # plugin Note
│   ├── media-player-ui.js     # mini player multimediale
│   ├── vpn-bind.js            # pannello VPN
│   └── settings-bind.js       # pannello impostazioni
├── landing/                   # sorgente del sito (Next.js, distribuito separatamente)
└── .github/workflows/
    └── build.yml               # CI/CD multipiattaforma
```
