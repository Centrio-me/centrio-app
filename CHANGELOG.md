# Changelog

All notable changes to Centrio are documented in this file.

This is a **technical companion to the in-app changelog** shown in the "История изменений" (version history) popup (`#changelogPopup` in `index.html`, starting at line 654). That in-app popup is the authoritative, always-up-to-date source of what shipped in each version — entries below are transcribed from it verbatim (in Russian, matching the source) and kept in [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format. When adding a new version to the in-app popup, add the matching entry here too.

The format is based on Keep a Changelog. This project does not currently follow strict Semantic Versioning (patch numbers are sometimes skipped or reused across build attempts), so version numbers should be read as chronological release identifiers rather than strict semver.

## [2.9.1]

- Исправлено (Centrio TEAM): сайты, назначенные владельцем организации сотруднику, иногда навсегда оставались белым окном и не загружались вовсе. Причина — проверка безопасности в главном процессе разрешала подключение вебвью только для личных мессенджеров пользователя, а назначенные через Тим специально не сохраняются локально (чтобы не расходиться со списком на сервере) — поэтому попадали под блокировку. Теперь для них есть отдельный, корректно работающий список разрешений
- Исправлено (Centrio TEAM): VPN у мессенджеров, назначенных через Тим, каждый раз при перезапуске приложения принудительно включался заново — даже если сотрудник явно выключил его для мессенджера, которому VPN не нужен. Теперь состояние VPN для таких мессенджеров сохраняется и больше не перезаписывается при следующем запуске

## [2.9.0]

- Новое: личный кабинет в приложении — поддержка и обращения прямо в Centrio (PRO). Список обращений, переписка с поддержкой и ответы — всё синхронизировано с личным кабинетом на сайте, включая обращения, созданные раньше через сайт. На кнопке «Поддержка» появляется значок с числом новых ответов, на которые вы ещё не отреагировали
- Новое: продление подписки в один клик. Если карта уже привязана (было оформлено продление с сохранением данных карты), кнопка «Продлить» в личном кабинете сразу списывает оплату и продлевает подписку — без перехода на сайт и повторного ввода карты
- Новое: горячие клавиши для сплит-экрана — `Ctrl+Shift+1…9` мгновенно открывает нужный сохранённый экран сплита по порядку в панели пресетов, добавлено в раздел «Горячие клавиши» настроек
- Новое: ассистенту рассказали про новые возможности приложения — он умеет открывать сохранённые экраны сплита по названию и отвечать на вопросы о статусе подписки (тариф, сколько дней осталось, место в команде Centrio TEAM)
- Улучшено: кнопка синхронизации с облаком в личном кабинете — иконка теперь по-настоящему крутится, пока идёт синхронизация, и на секунду показывает зелёную галочку по завершении, вместо простой смены надписи
- Улучшено: разбивка активности по мессенджерам в личном кабинете стала компактнее — показывает три самых используемых сервиса без громоздкого графика с полосками, который раньше занимал много места
- Исправлено: при запуске приложения мессенджеры и тема оформления иногда подгружались с устаревшими данными (например, тема неожиданно сбрасывалась на стандартную) — увеличен таймаут ожидания облачной синхронизации при старте, и её результат больше не отбрасывается, если пришёл чуть позже положенного
- Исправлено (Centrio TEAM): мессенджеры, назначенные владельцем организации, иногда не появлялись у сотрудника сразу после запуска приложения — добавлены быстрые повторные попытки синхронизации в первые секунды после старта
- Исправлено (Centrio TEAM): мессенджеры, назначенные владельцем организации, больше нельзя удалить со стороны сотрудника; владелец теперь может запретить сотруднику добавлять собственные мессенджеры сверх назначенных
- Исправлено (Centrio TEAM): логотип организации иногда не отображался в приложении даже после успешной загрузки в личном кабинете на сайте
- Исправлено: в сплит-экране (два окна, тройной сплит, 2×2) индикатор активной вкладки в шапке рядом с логотипом иногда показывал не ту вкладку, что реально была в фокусе
- Исправлено: горячие клавиши масштаба вкладки (Ctrl+ / Ctrl−) иногда не срабатывали — зависело от того, стоял ли фокус на самом приложении или внутри открытого мессенджера, и от того, какой клавиатурой (обычной или цифровой) вы пользовались
- Исправлено: экран блокировки — иконка удаления символа PIN-кода была визуально кривой, заменена на ровный крестик; панель с цифрами сделана уже; часы опущены чуть ниже; шрифт кнопок PIN-пада приведён к общему шрифту приложения (раньше рисовался системным шрифтом)
- Переименовано: кнопка «+» в сайдбаре теперь называется «Добавить сервис» вместо «Добавить мессенджер» — так понятнее для сервисов вроде почты, документов и CRM, которые мессенджерами не являются

## [2.8.3]

- Новое: VPN переведён на движок Xray-core (тот же, что использует Happ) для vmess/vless/trojan/shadowsocks, включая XHTTP/Reality/gRPC/WS/HTTPUpgrade транспорты — серверы, которые раньше не подключались вообще (в том числе с XHTTP), теперь работают так же, как в Happ. sing-box оставлен только для hysteria2-ссылок, которые Xray-core не поддерживает
- Улучшено: оба VPN-движка (Xray-core и sing-box) теперь вшиты прямо в установщик — скачивание с GitHub на машине пользователя больше не требуется вообще. Раньше движок докачивался при первом подключении VPN, и именно в тех сетях, где VPN и нужен, GitHub Releases нередко рвал соединение, из-за чего подключение иногда получалось только с нескольких попыток
- Исправлено: подключение/отключение/переключение VPN перезагружало вообще все открытые вкладки мессенджеров — теперь перезагружаются только те, у кого VPN реально включён и прокси действительно изменился
- Новое: в панели VPN — кнопки «Обновить пинг» и «Обновить» (список серверов из подписки), доступны и до подключения

## [2.8.2]

- Исправлено: VPN мог визуально «включаться», но сразу ломать WhatsApp и Telegram без возможности переподключения — воспроизведено с тривиальным локальным SOCKS5-релеем, показавшим, что дело не в VPN-узле: `session.setProxy()` меняет сетевую среду уже загруженной вкладки, и WhatsApp Web (не переживает это на своей стороне, IndexedDB-сессия) остаётся в разбитом состоянии навсегда. Main-процесс теперь шлёт `vpn-proxy-changed` после каждого реального применения прокси, рендерер перезагружает затронутые вкладки
- Исправлено: серверы с транспортом XHTTP не подключались вообще без какой-либо ошибки — sing-box (VPN-движок приложения) никогда не поддерживал этот транспорт ни в одной версии (PR в апстрим был закрыт без слияния), теперь показывается понятное сообщение вместо тихого "ничего не происходит"
- Исправлено: клавиша Esc теперь закрывает любые контекстные меню и попапы — раньше была подключена только к быстрому поиску и поиску по странице

- Исправлено: заметки могли пропадать и снова появляться / не синхронизироваться — сервер по ошибке применял общий лимит защиты от анонимных запросов (100 запросов/15 минут на IP) к заметкам и другим авторизованным разделам приложения (синхронизация, статистика, задачи, поддержка), из-за чего обычное набирание текста в заметке иногда «съедало» весь лимит

- Новое: «Чат для сайта» (Pro) — подключите виджет чата на свой сайт и получайте сообщения от посетителей прямо в Centrio, отдельной вкладкой мессенджера. Можно настроить цвет и логотип виджета под свой бренд. Функция помечена как «Альфа» — активно дорабатывается, сообщайте о багах

- Новое: задачи стали мощнее — сроки, приоритет, заметки, подзадачи и напоминания с уведомлением на рабочий стол
- Улучшено: блокировщик рекламы существенно расширен и теперь работает сразу для новых вкладок, без перезапуска приложения
