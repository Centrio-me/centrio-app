# Changelog

All notable changes to Centrio are documented in this file.

This is a **technical companion to the in-app changelog** shown in the "История изменений" (version history) popup (`#changelogPopup` in `index.html`, starting at line 654). That in-app popup is the authoritative, always-up-to-date source of what shipped in each version — entries below are transcribed from it verbatim (in Russian, matching the source) and kept in [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format. When adding a new version to the in-app popup, add the matching entry here too.

The format is based on Keep a Changelog. This project does not currently follow strict Semantic Versioning (patch numbers are sometimes skipped or reused across build attempts), so version numbers should be read as chronological release identifiers rather than strict semver.

## [2.5.3]

- Исправлено: на macOS не работали Cmd+C/Cmd+V и другие системные сочетания клавиш — восстановлено системное меню Edit
- Исправлено: вложения из Яндекс.Почты (и похожих веб-клиентов) не скачивались, открывался только предпросмотр во внешнем браузере
- Исправлено: кнопка мини-плеера не показывалась, когда играла ВК Музыка
- Новое: раздел «Видеозвонки» — Яндекс Телемост, Zoom, Google Meet, Microsoft Teams, Webex
- Новое: в «Продуктивность» добавлены AmoCRM, Мегаплан, RetailCRM
- Обновлена иконка VK Видео

## [2.5.2]

- Новое: добавлена Алиса PRO (alicepro.yandex.ru) в раздел «Нейросети»
- В разделе «Нейросети» убран дублирующий обычный значок SYNTAX — теперь показывается только большая промо-плитка (в «Популярных» обычный значок SYNTAX остался)

## [2.5.1]

- Исправлен мини-плеер — после обновления до 2.5.0 переставал показываться, даже когда музыка или видео играли в открытых мессенджерах
- Восстановлена промо-плитка SYNTAX в разделе «Нейросети»
- Программа стала ещё безопаснее

## [2.5.0]

- Новое: подписка Centrio TEAM — корпоративная версия для команд, покупка мест (seats), приглашение участников по ссылке, раздел «Команда» в личном кабинете
- Новое: мини-плеер справа — показывает, что сейчас играет в открытых мессенджерах (музыка или видео), с кнопками паузы, воспроизведения и переключения трека
- Новое: добавлены мессенджеры и сервисы — Element, Threema, Wire, Zalo, GroupMe, Threads, Snapchat, Google Meet, Webex, Chatwork, SYNTAX
- Новое: добавлен раздел «Медиа» — YouTube, Spotify, Яндекс Музыка, VK Видео, Shazam, Ivi, Кинопоиск и другие
- Исправлена иконка Я.Мессенджера
- Программа стала ещё безопаснее

## [2.4.0]

- Вход через Google, Яндекс и Grok больше не подвешивает приложение и не оставляет чёрный экран после закрытия окна авторизации — переработано всплывающее окно входа: устранена гонка при передаче данных входа обратно во вкладку мессенджера, вкладка теперь переходит на реальную страницу после успешного входа вместо простой перезагрузки
- Новое: ссылки-приглашения MAX (max.ru/join/...) и Telegram (t.me/..., tg://resolve, tg://join) теперь открываются в уже добавленной вкладке нужного мессенджера вместо внешнего браузера — работает и по клику внутри другого мессенджера, и по ссылке, открытой вне приложения; если подходящей вкладки нет, поведение как раньше — открытие во внешнем браузере

## [2.3.0]

- Исправлен баг: вход через Google, Яндекс и другие способы входа внутри мессенджеров мог открыть окно во внешнем браузере и не вернуться обратно в приложение — окно входа теперь всегда закрывается и возвращает в мессенджер после успешного входа
- Мессенджер «Яндекс Чат» переименован в «Я.Мессенджер», адрес обновлён на актуальный (yandex.ru/chat)
- Исправлен баг: копирование и вставка (Ctrl+C/Ctrl+V) могли молча не работать в некоторых мессенджерах — буфер обмена, звонки (микрофон/камера) и системные уведомления от самой страницы теперь разрешены явно
- Исправлен баг: при открытом сплит-экране уведомление о новом сообщении иногда дублировалось, даже если чат уже был виден на экране во второй панели
- Исправлен баг: статистика активности считала время только по основному (первому) мессенджеру в сплит-экране, даже если пользователь работал в другой открытой рядом вкладке — теперь время учитывается за тем окном, которое реально в фокусе

## [2.2.0]

- Новое: справа появился второй сайдбар — Ассистент (скоро), Планировщик задач и уведомления теперь там, а не слева
- Новое: Планировщик задач — можно создавать отдельные списки (категории) задач, закреплять важные, отмечать выполненные
- Новое: первый запуск теперь начинается с входа в аккаунт (Google, Яндекс или почта) или входа без аккаунта — при любом варианте даётся 14 дней Pro бесплатно
- Новое: левый сайдбар можно раскрывать — рядом с иконками мессенджеров появляются подписи
- Новое: внизу окна теперь видно статус подписки — с какого дня оплачена, сколько дней осталось, и кнопка «Продлить»
- Новая тема оформления «Встроенная» — единый фон окна и скруглённые углы активной вкладки, теперь тема по умолчанию
- Плотность интерфейса (Компактно / Обычно / Комфортно) в настройках теперь по-настоящему меняет размер сайдбара и иконок
- Кнопка «+» добавления мессенджера теперь заранее показывает метку PRO, если бесплатный лимит (3 мессенджера) уже достигнут
- Восстановлена оплата зарубежными картами в личном кабинете на сайте
- Исправлена подсветка активного мессенджера в сайдбаре — теперь мягкое цветное свечение вокруг иконки
- Мелкие визуальные правки: кружки-счётчики непрочитанных, отступы и вёрстка сайдбаров
