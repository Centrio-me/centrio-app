## 为什么选择 Centrio？

Telegram 开在一个窗口，WhatsApp 开在另一个，Discord 又是第三个。Gmail 在浏览器标签页里，Notion 不知道在哪，Slack 还在后台响个不停。

**Centrio 把它们全部集中到一处** —— 一个桌面应用，每个服务都有自己的标签页，通知统一管理，终于可以把浏览器里的 14 个标签页都关掉了。

## 功能

### 🗂️ 100+ 服务，一个侧边栏

Telegram · WhatsApp · Discord · VK · Slack · Notion · Gmail · Signal · Zoom · WeChat · LINE · Figma · Jira · MAX · 以及任何你手动添加的网址。

### 🤖 AI 助手 *(Pro/Team)*

用日常语言直接吩咐它：切换标签页、查看未读数量、读取通知铃铛内容、控制内置 VPN、操作迷你播放器，还能创建、置顶或删除你的笔记。

### 📝 笔记 *(Pro/Team)*

一个真正完整的笔记插件，而不是附加功能：普通笔记和购物清单，跨设备同步。

- 🔍 对笔记内容和清单项进行全文搜索
- 🎨 六种颜色标签，快速视觉分类
- 🗄️ 归档 —— 不删除也能把笔记收起来
- ↕️ 拖拽排序
- 📌 置顶、📋 复制，每张卡片都显示最后修改时间

### 🛡️ 内置 VPN

无需第三方应用。导入配置链接，一键连接。

| 协议 | 导入格式 |
|------|---------|
| VLESS | `vless://...` |
| VMess | `vmess://...` |
| Trojan | `trojan://...` |
| Shadowsocks | `ss://...` |
| Hysteria2 | `hy2://...` |
| 订阅 | 含配置列表的 URL |

延迟指示灯（绿/黄/红）、国家旗帜、连接计时、自动切换备用服务器、所有会话的流量路由。

### 🎵 迷你播放器

只要任意打开的标签页开始播放音频或视频，侧边栏就会出现图标 —— 无需切换过去即可暂停、切换上一曲/下一曲。

### 🧩 Chrome 扩展 *(Pro/Team)*

直接在 Centrio 内安装 AdBlock、Grammarly、翻译等扩展 —— 不需要单独的浏览器。

### ✅ 待办事项

一个轻量任务规划器，支持自定义分类（列表）—— 添加、加星标、完成，可以删除单个任务，也可以删除整个列表。

## 从源码构建

```bash
git clone https://github.com/Centrio-me/centrio-app.git
cd centrio-app
npm install
cp .env.example .env   # 填写 OAuth 凭据
```

```bash
npm start              # 开发模式
npm run build:win      # → dist/Centrio Setup x.x.x.exe
npm run build:mac      # → dist/Centrio-x.x.x.dmg
npm run build:linux    # → dist/Centrio-x.x.x.AppImage + .deb
```

**环境要求：** Node.js 22+，npm 10+

## CI/CD

每次推送 `v*` 标签都会触发多平台 GitHub Actions 构建：

```
git tag v2.x.x && git push origin v2.x.x
        │
        ├─ build-win   (windows-latest)  →  .exe
        ├─ build-mac   (macos-latest)    →  .dmg
        └─ build-linux (ubuntu-latest)   →  .AppImage + .deb
                │
                └─ deploy  →  上传至 download.centrio.me
```

所需 Secrets：`SSH_HOST`、`SSH_USER`、`SSH_PASSWORD`、`GOOGLE_DESKTOP_CLIENT_ID`、`GOOGLE_DESKTOP_CLIENT_SECRET`、`YANDEX_CLIENT_ID`、`YANDEX_CLIENT_SECRET`、`TELEGRAM_BOT_ID`

## 项目结构

```
centrio-app/
├── main.js                  # Electron 主进程入口
├── preload.js                # 主窗口的 contextBridge preload
├── webview-preload.js        # 注入到每个通讯软件 <webview> 的 preload
├── vpn-manager.js             # sing-box 进程管理器
├── main/
│   ├── bootstrap/            # 应用初始化、窗口创建、IPC 注册
│   ├── factory/               # BrowserWindow / 模态窗口工厂
│   ├── ipc/                   # VPN、代理、OAuth、助手、笔记、更新器……
│   └── services/              # 存储、安全存储、权益、aiProviders……
├── renderer.js                # 渲染进程入口 —— 装配所有 renderer/*.js 模块
├── renderer/                  # 原生 JS + esbuild，每个功能一个模块
│   ├── assistant-bind.js      # AI 助手聊天界面
│   ├── notes-bind.js          # 笔记插件
│   ├── media-player-ui.js     # 迷你播放器
│   ├── vpn-bind.js            # VPN 面板
│   └── settings-bind.js       # 设置面板
├── landing/                   # 官网源码（Next.js，单独部署）
└── .github/workflows/
    └── build.yml               # 多平台 CI/CD
```
