## Pourquoi Centrio ?

Vous avez Telegram ouvert dans une fenêtre, WhatsApp dans une autre, Discord dans une troisième. Gmail dans un onglet du navigateur. Notion quelque part. Slack qui bipe en arrière-plan.

**Centrio rassemble tout ça au même endroit** — une seule application de bureau où chaque service vit dans son propre onglet, les notifications sont unifiées, et vous pouvez enfin fermer 14 onglets de navigateur.

---

## Fonctionnalités

### 🗂️ Plus de 100 services, une seule barre latérale

Telegram · WhatsApp · Discord · VK · Slack · Notion · Gmail · Signal · Zoom · WeChat · LINE · Figma · Jira · MAX · et n'importe quelle URL ajoutée manuellement.

### 🤖 Assistant IA *(Pro/Team)*

Demandez-lui en langage naturel et il s'en charge : changer d'onglet, vérifier les messages non lus, lire la cloche de notifications, contrôler le VPN intégré, piloter le mini lecteur multimédia, et gérer vos notes — création, épinglage, suppression sur demande.

### 📝 Notes *(Pro/Team)*

Un vrai plugin de notes, pas un à-côté : notes simples et listes de courses, synchronisées sur tous vos appareils.

- 🔍 Recherche en texte intégral dans les notes et les éléments de liste
- 🎨 Six étiquettes de couleur pour un tri visuel rapide
- 🗄️ Archive — écarter une note sans la supprimer
- ↕️ Réorganisation par glisser-déposer
- 📌 Épinglage, 📋 duplication, et une date de dernière modification sur chaque carte

### 🛡️ VPN intégré

Aucune application tierce nécessaire. Importez un lien de configuration et connectez-vous en un clic.

| Protocole | Format d'import |
|-----------|-----------------|
| VLESS | `vless://...` |
| VMess | `vmess://...` |
| Trojan | `trojan://...` |
| Shadowsocks | `ss://...` |
| Hysteria2 | `hy2://...` |
| Abonnement | URL avec liste de configurations |

Indicateur de ping (vert / jaune / rouge), drapeau du pays, minuteur de connexion, bascule automatique vers un serveur de secours, routage du trafic pour toutes les sessions.

### 🎵 Mini lecteur multimédia

Une icône apparaît dans la barre latérale dès qu'un audio ou une vidéo commence à jouer dans un onglet ouvert — pause, piste suivante et précédente sans changer d'onglet.

### 🧩 Extensions Chrome *(Pro/Team)*

Installez AdBlock, Grammarly, un traducteur et d'autres extensions directement dans Centrio — pas besoin d'un navigateur séparé.

### ✅ Tâches

Un gestionnaire de tâches léger avec ses propres catégories (listes) — ajoutez, marquez d'une étoile, terminez, et supprimez aussi bien des tâches individuelles que des listes entières.

## Compiler depuis les sources

```bash
git clone https://github.com/ArtemkaFreedom/centrio-app.git
cd centrio-app
npm install
cp .env.example .env   # renseignez les identifiants OAuth
```

```bash
npm start              # développement
npm run build:win      # → dist/Centrio Setup x.x.x.exe
npm run build:mac      # → dist/Centrio-x.x.x.dmg
npm run build:linux    # → dist/Centrio-x.x.x.AppImage + .deb
```

**Prérequis :** Node.js 22+, npm 10+

## CI/CD

Chaque tag `v*` déclenche une build multiplateforme via GitHub Actions :

```
git tag v2.x.x && git push origin v2.x.x
        │
        ├─ build-win   (windows-latest)  →  .exe
        ├─ build-mac   (macos-latest)    →  .dmg
        └─ build-linux (ubuntu-latest)   →  .AppImage + .deb
                │
                └─ deploy  →  envoi vers download.centrio.me
```

Secrets requis : `SSH_HOST`, `SSH_USER`, `SSH_PASSWORD`, `GOOGLE_DESKTOP_CLIENT_ID`, `GOOGLE_DESKTOP_CLIENT_SECRET`, `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `TELEGRAM_BOT_ID`

## Architecture

```
centrio-app/
├── main.js                  # point d'entrée du processus principal Electron
├── preload.js                # contextBridge preload (fenêtre principale)
├── webview-preload.js        # preload injecté dans chaque <webview> de messagerie
├── vpn-manager.js             # gestionnaire du processus sing-box
├── main/
│   ├── bootstrap/            # initialisation de l'app, création de fenêtre, IPC
│   ├── factory/               # fabriques de BrowserWindow / fenêtres modales
│   ├── ipc/                   # VPN, proxy, OAuth, assistant, notes, updater...
│   └── services/              # store, stockage sécurisé, entitlement, aiProviders...
├── renderer.js                # point d'entrée du renderer — connecte tous les renderer/*.js
├── renderer/                  # JS pur + esbuild, un module par fonctionnalité
│   ├── assistant-bind.js      # UI du chat de l'assistant IA
│   ├── notes-bind.js          # plugin Notes
│   ├── media-player-ui.js     # mini lecteur multimédia
│   ├── vpn-bind.js            # panneau VPN
│   └── settings-bind.js       # panneau de réglages
├── landing/                   # source du site vitrine (Next.js, déployé séparément)
└── .github/workflows/
    └── build.yml               # CI/CD multiplateforme
```
